# rails-task-manager

The starting scaffold for a Rails "task manager" (to-do list CRUD) exercise from the Le Wagon web development bootcamp.

## Context

Created on 2020-07-21 during the Le Wagon bootcamp. The repository has a single commit, `rails new`. It contains the default Rails 6 application generated by that command and nothing else.

## What is in it

- A freshly generated Rails 6.0.3 app (Ruby 2.6.6) with SQLite, Puma, Webpacker 4, Sass and Turbolinks.
- No models, migrations, controllers, views or routes have been added. `config/routes.rb` is empty.
- The task CRUD that the exercise asks for (list, show, create, edit and delete tasks) was never committed here.

## Running it

With Ruby 2.6.6, Bundler, Node and Yarn installed:

```sh
bundle install
yarn install
bin/rails server
```

This only shows the default Rails welcome page.

## Status

Archived learning project, not maintained. It is kept for reference only. It does not represent production work.
